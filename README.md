# haroonsukhera.com — starter pack

Everything Antigravity needs to build the site: rules, page plans, approved copy, design system, SEO setup, all images, your edited photos, the mockup script, and working code from the Webix Solutions site to reuse.

## How to start (10 minutes)
1. Create a new empty GitHub repo: `webixsolutions-dev/haroonsukhera-site` (private is fine).
2. Unzip this pack into it and push (`git add . && git commit -m "Starter pack" && git push`).
3. Open the folder in Antigravity.
4. Open `prompts/PROMPTS.md` and paste **Phase 0** into a new Antigravity conversation (Planning mode). Approve the plan. Then Phase 1, 2, 3… one per conversation.
5. After each phase, check the screenshots it shows you. Only move on when they look right.

## What's inside
| Folder | What |
|---|---|
| `AGENTS.md`, `.agents/rules/` | Rules Antigravity follows on every task (stack, design, SEO/AI, truth and voice) |
| `docs/` | The plan: facts, pages, copy, design system, SEO/AI, portfolio, image map, open questions |
| `prompts/PROMPTS.md` | Phase-by-phase prompts to paste |
| `public/images/` | All website images (optimised) + your edited photos |
| `assets/` | Mockup scenes with green screens + your original photos |
| `scripts/` | `shots.mjs` (website screenshots) and `compose_mockups.py` (puts screenshots onto the device scenes) |
| `reference/webix/` | Working code from the Webix site to reuse: booking, contact form API, schema helpers, cookie consent, Cloudflare config, QA scripts |
